# SecScanner

**SecScanner** is a Python-based command-line security analysis tool that leverages Google's Gemini API to analyze code and identify potential security vulnerabilities. It generates structured security findings, categorizes issues by severity, and produces an HTML report to help developers review and understand potential risks in their code.

### Features
- **AI-Powered Code Analysis:** Uses Google's Gemini API to analyze source code for potential security vulnerabilities.
- **Structured Findings:** Organizes vulnerability results into structured JSON output for consistent processing.
- **Severity Classification:** Categorizes findings by severity to help prioritize remediation.
- **HTML Reporting:** Generates readable HTML reports using Jinja2 templates.
- **Command-Line Interface:** Provides a lightweight CLI workflow for running scans and reviewing results.

### Technologies
Python • Google Gemini API • JSON • Jinja2 • Colorama • dotenv

### Purpose
Built as a personal project exploring AI-assisted security analysis, Python automation, and the presentation of security findings in a developer-friendly format.
