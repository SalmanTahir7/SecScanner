CRITICAL

Type: SQL Injection

Description:

User input is directly concatenated into a SQL query.

Impact:

Full database compromise or unauthorized data access.

Recommended Fix

Use parameterized queries (e.g., cursor.execute('SELECT * FROM users WHERE username = ?', (username,)))

CRITICAL

Type: OS Command Injection

Description:

User input is passed directly to os.system.

Impact:

Remote Code Execution (RCE) on the host system.

Recommended Fix

Avoid using os.system with user input; use the subprocess module with shell=False and pass arguments as a list.
